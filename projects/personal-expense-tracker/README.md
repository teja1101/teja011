# Personal Expense Tracker

A beginner-friendly full-stack Python web application for recording income and expenses, monitoring balance, filtering transactions, and visualizing spending patterns.

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- Chart.js

## Features

- Add income and expense transactions
- Edit and delete transactions
- Category-based tracking
- Filter by month, category, and transaction type
- Dashboard totals for income, expense, balance, and transaction count
- Expense-by-category doughnut chart
- Monthly income-vs-expense bar chart
- CSV export
- Responsive dark UI
- SQLite persistent storage
- Server-side validation

## Run Locally

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```

Open `http://127.0.0.1:5000`.
