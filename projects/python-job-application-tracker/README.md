# Job Application Tracker

A responsive full-stack beginner Python project for managing job applications.

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2

## Features

- Add job applications
- Edit applications
- Delete applications
- Search by company, role, or notes
- Filter by application status
- Dashboard statistics
- Export applications to CSV
- Responsive dark user interface
- Persistent SQLite storage
- Form validation

## Run Locally

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install Flask:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
